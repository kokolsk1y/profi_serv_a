# N8N Production Setup

This is a n8n workflow automation setup running on Railway.

## Setup

1. Copy `.env.example` to `.env` and update the values
2. Deploy to Railway using docker-compose.yml
3. Access the application at https://n8n-production-7fb5.up.railway.app

## Configuration

- Database: PostgreSQL 15
- N8N Version: Latest
- Hosting: Railway.app
